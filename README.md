# Global News Market Impact

미국 주요 기술 기업의 과거 뉴스에서 키워드·구문·사건 유형과 표현 맥락을 분석하고, 이후 주가 움직임을 시각화하는 프로젝트입니다.

2026-09-07에 예측모델 학습·성능 비교에서 뉴스 패턴 분석·시각화 중심으로 방향을 변경했습니다. 현재는 스키마·시장 세션·가격 검증·배치 라벨 기반을 구현한 단계입니다. 분석 화면과 실제 뉴스 데이터셋은 아직 구현하지 않았습니다.

## 핵심 질문

- 시기별로 어떤 키워드와 구문이 자주 등장했는가?
- 사건 유형과 표현 맥락에 따라 이후 수익률 분포가 어떻게 달랐는가?
- 해당 종목의 기본 상승 비율과 QQQ·SPY 대비 반응에서도 차이가 보이는가?
- 앞선 기간에서 발견한 패턴이 이후 기간에도 유지되는가? 반대 사례는 무엇인가?

과거 반응과 근거 기사를 탐색하는 화면이 현재 MVP의 결과물입니다. 새 기사 입력과 유사 사례 검색은 분석을 검증한 뒤 검토합니다. 과거 상승 비율을 검증된 미래 상승 확률로 표현하거나 관측된 차이를 뉴스의 인과 효과로 단정하지 않습니다.

## 현재 구현 상태

완료된 기반 작업:

- 기사·가격·시장 심리·이벤트·전체 학습 행의 컬럼 계약
- 기사 라벨링 최소 입력 컬럼 검증, 비어 있거나 중복된 기사 ID 차단, 입력 순서·추가 컬럼 보존
- 공급자 원본 시각을 보존하는 `*_original`과 미국 동부시간 정규화 값인 `*_et` 계약
- `exchange-calendars`의 `XNYS` 일정에 따른 프리마켓·장중·장 마감 후·주말·휴장일·조기 폐장 세션 선택
- 폐장 직후 1분 모호 구간 차단과 유효한 양수 종가 검증
- 세 실험의 모델 feature 분리 및 미래 가격·target 누수 방지 테스트
- 가격표 필수 컬럼·거래일·티커·중복 검증과 두 세션 가격 행 선택
- 가격표 1회 정규화 재사용과 요청한 종목·거래일 키에 한정한 중복 차단
- 일봉 거래일의 timezone-aware datetime 입력 차단
- 조정 종가 라벨 생성, 원본 종가 감사 보존, QQQ·SPY 동일 거래일 연결
- 누락·중복·비정상 가격·폐장 경계를 구조화한 제외 결과와 문제 가격의 종목·거래일·필드 정보
- 기사·가격표를 한 번씩만 준비하고 입력 순번을 보존하는 성공·제외 배치 라벨 결과표
- 종목·QQQ·SPY 단순 수익률과 두 benchmark 대비 초과수익률 계산
- 종목·QQQ·SPY의 이전·이후 거래일 일치 검증
- 미래 수익률·초과수익률의 모델 feature 혼입 방지

아직 구현하지 않은 범위:

- 뉴스 공급자 확보 가능성 조사와 실제 뉴스 데이터셋 수집
- Tiingo 어댑터, 실제 가격 연결과 제외 사유 집계
- 원본 시각의 런타임 정규화, 사건 묶음과 패턴 분류
- 패턴별 통계, 후속 기간 검증, 사건 전후 여러 거래일 수익률과 시각화

모델 학습·성능 비교와 시장 심리·이벤트 join은 현재 MVP의 필수 작업에서 제외합니다. 기존 feature 분리 계약과 테스트는 보존합니다.

2026-09-04 Vault의 소량 표본 검증 기록에서 분할·현금 배당 조정을 확인한 Tiingo를 주 가격 공급자로 결정했습니다. 토스증권은 공개 시장 데이터의 소량 교차검증용입니다. 이 결정은 어댑터 구현이나 전체 기간 수집 완료를 뜻하지 않습니다. Tiingo `date`는 시간대 변환으로 날짜를 이동시키지 않고 공급자가 부여한 날짜 부분을 `trading_date`로 파싱해야 합니다. 허용 호스트·경로 검사와 토큰 마스킹도 어댑터 구현 전에 강제합니다.

기존 상승·비상승 라벨은 과거 상승 비율의 보조 집계에 활용할 수 있습니다. 분석의 중심은 연속 수익률과 분포이며 이진 라벨만으로 패턴을 평가하지 않습니다.

## 주요 정책 및 경제 이벤트

시장 심리·정책·경제 이벤트의 별도 수집과 join은 기본 패턴 분석 이후 필요성이 확인될 때 검토합니다. 기존 후보는 다음과 같습니다.

- 관세·무역·반도체·AI 규제 발표
- 기준금리 결정과 통화정책 발표
- CPI와 고용지표 발표

Truth Social과 백악관 공식 발표는 기존 후보 출처이며, 시장 또는 대상 산업 관련 내용만 검토합니다. 최근 24시간 이벤트 플래그는 현재 MVP의 필수 입력이 아닙니다.

## 필요한 데이터

### 기업 뉴스

```text
article_id, title, summary, published_at_original, published_at_et, source, url, ticker
```

- `published_at_original`에는 공급자 원본 시각과 시간대를 보존
- `published_at_et`에는 미국 동부시간 정규화 값을 저장
- 최초 게시 시각과 수정 시각 구분
- 기업명과 티커 연결
- 동일 사건의 중복 기사 식별
- 기사 전문 대신 제목과 요약 중심으로 시작

### 종목 및 시장 가격

```text
ticker, trading_date, open, high, low, close, adjusted_close, volume
```

- 대상 8개 기업의 일봉
- 시장 비교용 QQQ와 SPY 일봉
- 미국 증시 거래일과 휴장일

### 시장 심리 보류

```text
sentiment_id, observed_at_original, observed_at_et, available_at_original, available_at_et, sentiment_value, sentiment_source
```

다음은 보류된 확장용 스키마입니다. 기존 대안은 공포·탐욕지수 확보가 어려울 때 VIX를 검토하는 것이며 현재 필수 수집 대상은 아닙니다.
원본 관측·가용 시각과 ET 정규화 시각을 함께 저장하며, feature join에는 기사 게시 전에 이미
사용 가능했던 `available_at_et` 기준 값만 사용합니다.

### 정책 및 경제 이벤트 보류

```text
event_id, event_type, published_at_original, published_at_et, available_at_original, available_at_et, source, title, importance
```

기존 이벤트 상수 `TARIFF_POLICY`, `FOMC`, `CPI`, `EMPLOYMENT`는 보존합니다. 뉴스의 사건 유형 분류표와는 별개이며, 새 분류표는 표본을 확인한 뒤 정합니다.
이벤트 역시 원본 게시·가용 시각을 보존하고, join 판단에는 ET 정규화 시각을 사용합니다.

## 시간축 결합 규칙

기사 시각을 미국 동부시간으로 정규화하고 정확한 시각과 거래소 일정으로 가격 구간을 연결합니다. 원본 시간대와 시각은 보존합니다. 아래의 세션·라벨 규칙은 현재 코드의 동작이며 새 분석의 최종 관측 기준을 뜻하지 않습니다.

장중 기사에 사용하는 전일 종가 → 당일 종가 수익률에는 기사 이전 움직임이 포함됩니다. 이를 순수한 기사 이후 반응으로 해석하지 않습니다. 1차 분석은 장 마감 후부터 다음 개장 전까지의 기사로 좁히는 방향이며, 주말·휴일 포함과 정확한 관측 구간은 표본 확인 후 확정합니다.

전일 종가 대비 다음 종가와 다음 시가 대비 종가 수익률은 구분합니다. 시가 기준을 추가할 때는 가격 조정 기준을 일치시켜야 하며, 기준 가격이 기사 시점의 실제 체결 가능 가격이었다고 가정하지 않습니다. 사건 전후 누적 수익률의 기간·계산 방식도 미확정입니다.

가격 데이터에는 기사 직전 거래일과 기사 이후 첫 정규장의 시가·종가·조정 종가·거래량이 필요합니다. 대상 8개
종목과 QQQ·SPY에 동일한 거래일 기준을 적용하고, 미국 증시 휴장일과 조기 폐장일도 반영합니다.

QQQ는 Nasdaq-100, SPY는 S&P 500 시장 벤치마크로 사용합니다. 두 ETF는 8개 분석 대상 종목에 추가하지 않고 초기 모델 feature에서도 제외합니다. 원본 `close`는 감사용으로 보존하고, 주식 분할과 분배금에 따른 가격 단절을 줄이기 위해 라벨과 향후 벤치마크 대비 수익률에는 `adjusted_close`를 사용합니다. 실제 데이터 적용 전에는 공급자의 조정 방식을 확인합니다.

기사 게시 시점별 기본 처리 규칙은 다음과 같습니다.

- 프리마켓 기사: 직전 거래일 종가와 당일 정규장 종가를 비교
- 장중 기사: 직전 거래일 종가와 당일 정규장 종가를 비교
- 폐장 시각부터 1분 미만: 종가 확정 여부가 모호하므로 라벨 날짜를 선택하지 않고 제외
- 장 마감 후 기사: 실제 폐장 1분 후부터 당일 정규장 종가와 다음 정규장 종가를 비교
- 주말·휴일 기사: 직전 개장일 종가와 다음 개장일 종가를 비교
- 조기 폐장일: 고정 16:00이 아닌 `XNYS`의 실제 폐장 시각을 기준으로 동일한 1분 규칙 적용
- 상승 라벨: 유한한 양수 조정 종가 두 개가 모두 검증되고 첫 정규장 조정 종가가 더 높을 때 생성
- 비상승 라벨: 유효한 두 조정 종가가 같거나 첫 정규장 조정 종가가 더 낮을 때 생성

이 규칙은 일봉 기반 MVP에서 장중·장외·주말 기사를 일관되게 처리하기 위한 초기안입니다.
장중 기사 반응을 더 세밀하게 측정할 필요가 확인되면 분봉 데이터를 사용하는 방식으로
확장합니다.

거래소 캘린더 범위는 현재 MVP 수집 기간과 개발 여유를 포함하도록 2020-01-01부터 2030-12-31까지 명시합니다. 승인된 데이터 기간이 이 범위를 벗어나면 상수를 함께 확장합니다.

`None`, 문자열, bool, `NaN`, 무한대, 0 이하 가격은 `비상승`으로 간주하지 않고 라벨 생성을
명시적으로 차단합니다.

정책 및 경제 이벤트 역시 기사보다 먼저 발표된 정보만 연결합니다. 기사 이후 발표된 관세,
금리, CPI, 고용지표나 당일 종가로 확정되는 시장 심리 값을 입력에 포함하면 미래 정보가
섞이므로 사용할 수 없습니다.

## 예상 처리 흐름

```text
뉴스 확보 가능성 조사와 표본 점검
-> 사건 유형·구문·동일 사건 묶음 기준과 관측 구간 확정
-> 기사 시각 정규화와 Tiingo 가격 연결, 제외 사유 기록
-> 패턴별 빈도·수익률 분포·시장 대비 차이 분석
-> 기준을 고정한 후속 기간 검증
-> 네 가지 시각화와 근거 기사 탐색
```

동일 기사 중복 제거와 동일 사건 묶음은 구분합니다. 원문 기사와 ID를 보존하고 같은 사건의 여러 기사를 독립 표본처럼 세지 않습니다. 같은 종목·거래 구간에서 사건이 겹치는 경우도 표시합니다.

## 패턴 검증

초기에는 수동 점검과 명시적인 구문 규칙으로 분류합니다. 실적 예상 상회·하회, 가이던스 상향·하향, 규제 검토·시행·예외 허용은 후보이며 분류표는 실제 표본에서 정합니다.

앞선 기간에서 패턴을 찾고 뒤의 기간에서는 분류·집계 기준을 고정해 확인합니다. 후보와 제외 기준을 기록해 잘 나온 패턴만 보고하는 일을 줄입니다. 기본 상승 비율, 시장 대비 수익률, 표본 수, 불확실성과 반대 사례를 함께 제시합니다. 최소 표본 수와 구간 추정 방법은 아직 확정하지 않았습니다.

## 이전 모델 비교 계획

아래는 2026-09-07 이전 계획과 기존 스키마 계약을 보존한 기록입니다. 현재 MVP의 실행 대상이 아닙니다.

1. 기사 제목과 요약만 사용하는 기준 모델
2. 기사와 전일 공포·탐욕지수를 사용하는 모델
3. 기사, 전일 공포·탐욕지수, 주요 이벤트 플래그를 사용하는 모델

세 feature 목록은 뉴스 → 뉴스+시장 심리 → 뉴스+시장 심리+이벤트 순서로 정확히 누적됩니다.
`ticker`, 식별자, 게시·가용 시각, 이벤트 윈도우, 세션 날짜, 두 가격, `label`은 모델 feature에
포함하지 않습니다. 이 값들은 식별·감사·라벨 생성·평가 용도로만 전체 학습 행에 보존합니다.

평가는 시간순으로 학습·검증 데이터를 나누고 Accuracy, Macro F1, 상승 확률의 신뢰도를
비교합니다. 기사 이후 정보가 입력에 포함되는 데이터 누출을 반드시 방지합니다.
